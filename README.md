🔐 Password Security Checker

A beginner-friendly cybersecurity project built with Python.

Overview

This program evaluates a sample password against five basic criteria and reports which checks pass.

Features

* Checks password length (at least 8 characters)
* Detects uppercase letters
* Detects lowercase letters
* Detects numbers
* Detects special characters
* Displays a summary of passed checks

Technologies

* Python 3
* Dictionaries and loops
* Conditional statements
* String methods

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Run:
    python password_checker.py

Example Output

=== PASSWORD SECURITY CHECKER ===
[PASS] At least 8 characters
[PASS] Uppercase letter
[PASS] Lowercase letter
[PASS] Number
[PASS] Special character
Checks passed: 5 out of 5
Result: All basic checks passed

Limitations

This is an educational project. Passing these checks does not guarantee password security. The current version uses a hardcoded sample password and does not measure password unpredictability or check against compromised passwords.
