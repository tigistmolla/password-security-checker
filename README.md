🔐 Password Security Checker

A beginner-friendly cybersecurity project built with Python.

Overview

This program checks a sample password against five basic criteria.

Features

* Checks whether the password has at least 12 characters
* Detects uppercase and lowercase letters
* Detects numbers
* Detects special characters
* Displays a summary of passed checks

Technologies

* Python 3
* Dictionaries and loops
* Conditional statements
* String methods

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Run python password_checker.py.

Security Limitations

This is an educational project, not a complete password-security assessment. Passing these checks does not guarantee a secure password. The current version uses a hardcoded sample password for demonstration. Never put your real password in the source code.
